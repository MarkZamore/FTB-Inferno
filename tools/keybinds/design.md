# Пресет управления FTB Inferno

Основа — сохранённый `options.txt` из прогона `ftb-public494-window-title-r2` на Minecraft 1.18.2, Forge 40.2.34 и Java 17. Снимок содержит 251 строку. Набор имён и число повторов совпадают с сохранённым `options.txt` установленной ревизии 5d54afb. Для сверки авторских значений использован `config/defaultoptions/keybindings.txt` из той же поставки, SHA-256 `31d16b4e81e1feae7382f9b66d0d8c840f33cc7bb45101ad57faeff1d8043c07`.

Все 34 базовых записи Minecraft сохранены. G открывает квестбук, M — карту, B — рюкзак Sophisticated Backpacks, H — книгу Ars Nouveau, R и U — рецепты и применения JEI. Стрелки управляют метлой Enchanted. У метлы отдельные клавиши, поскольку Enchanted регистрирует её через обычный конструктор KeyMapping. У Grappling Hook собственный контекст и обработчик, поэтому основные действия крюка получили отдельные кнопки мыши, а дополнительные — цифровой блок. Буквенные клавиши JEI оставлены отдельно от действий игрового мира. В JEI 9.7.2.1001 проверены экранный и специальные контексты наведения.

Пресет допускает одну запись на физическую клавишу. Сочетания с Shift, Ctrl и Alt сняты, чтобы удерживание модификатора и пользовательские контексты модов не создавали скрытого пересечения. Необязательные действия можно назначить вручную. Пары регистраций EvilCraft с одинаковыми именами обе получают «Не назначена». Три имени MineTogether содержат двоеточие и не представимы текущим форматом пресета, в обоих снимках они сняты.

Тест охватывает записи из сохранённых снимков и назначения в пресете. Независимые обработчики модов и сочетания вне массива сохраняемых назначений могут иметь собственные клавиши. Minecraft для проверки пресета не запускался.

После обновления автора сверьте инвентарь назначений с новой версией клиента, пересмотрите LAYOUT и выполните:

    python -B tools/keybinds/build_preset.py
    python -B tools/keybinds/check_preset.py

Публикация пресета выполняется workflow `publish.yml`. Он сохраняет остальные файлы и шейдеры действующего выпуска. После полной замены авторской поставки запустите этот workflow вручную, чтобы снова внести актуальный пресет в манифест.
